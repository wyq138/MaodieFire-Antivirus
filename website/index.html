架构设计

模块化双进程架构，各功能独立开发，通过项目引用集成到主程序

🖥️ 主程序进程

FireAntivirus.exe

类型：WinExe (WPF)

职责：WPF 界面程序，用户交互入口

功能：提供完整图形界面，包括病毒扫描界面、实时防护面板、防火墙配置、安全报告查看等所有用户可操作功能

🛡️ 后台防护进程

FireAntivirus.ServiceHost.exe

类型：Exe (后台守护)

职责：后台守护进程，提供持续安全防护

模式：支持 Windows 服务模式、控制台模式（调试）、独立运行模式

特性：主程序关闭后继续运行，提供持续防护和进程守护（自动重启主程序）
